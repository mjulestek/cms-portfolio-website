1. Final Architecture

GitHub

Source code and workflow

→

Actions

Builds and deploys

→

ECR

Stores Docker image

→

EC2

Runs app container

Full flow: git push → GitHub Actions → Docker build → ECR push → SSH to EC2 → ECR pull → Docker Compose restart → MongoDB Atlas connection → live app.

MongoDB Atlas

Production database. Do not run production MongoDB inside EC2.

S3

Stores uploaded media, resumes, images, icons, and PDFs.

CloudFront

Serves S3 files quickly. The full app can be placed behind CloudFront later.

Secrets

Production values live in GitHub Secrets and are passed during deployment.

3. Production Dockerfile

This Dockerfile is for the image GitHub Actions builds and pushes to ECR.

FROM node:20-alpine

WORKDIR /app

RUN apk add --no-cache openssl libc6-compat

ENV PRISMA_CLI_BINARY_TARGETS=linux-musl-openssl-3.0.x

COPY package*.json ./
RUN npm install

COPY . .

RUN npx prisma generate
RUN npm run build

EXPOSE 3000

CMD ["npm", "start"]
Prisma note: In prisma/schema.prisma, use binaryTargets = ["native", "linux-musl-openssl-3.0.x"] for Alpine.

5. MongoDB Atlas

  1. Create a MongoDB Atlas cluster.
  2. Create a database user.
  3. Add the EC2 public IP in Network Access.
  4. Copy the connection string.
Important: the database name must be inside the URL.

Wrong:

mongodb+srv://USER:PASSWORD@CLUSTER.mongodb.net/?retryWrites=true&w=majority

Correct:

mongodb+srv://USER:PASSWORD@CLUSTER.mongodb.net/jules_portfolio_cms?retryWrites=true&w=majority

10. GitHub Actions Workflow

Create .github/workflows/deploy.yml.

Full MVP deploy workflow
name: Deploy

on:
  push:
    branches: [main]

jobs:
  build-and-push:
    name: Build and push image to ECR
    runs-on: ubuntu-latest

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Login to AWS
        uses: aws-actions/configure-aws-credentials@v4
        with:
          aws-access-key-id: ${{ secrets.AWS_ACCESS_KEY_ID }}
          aws-secret-access-key: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
          aws-region: ${{ secrets.AWS_REGION }}

      - name: Login to ECR
        uses: aws-actions/amazon-ecr-login@v2

      - name: Build and push Docker image
        run: |
          IMAGE="${{ secrets.AWS_ACCOUNT_ID }}.dkr.ecr.${{ secrets.AWS_REGION }}.amazonaws.com/${{ secrets.ECR_REPOSITORY_NAME }}:latest"
          docker build -t "$IMAGE" .
          docker push "$IMAGE"

  deploy-to-ec2:
    name: Pull image and run on EC2
    runs-on: ubuntu-latest
    needs: build-and-push

    steps:
      - name: Deploy on EC2
        uses: appleboy/ssh-action@v1.2.0
        env:
          AWS_REGION: ${{ secrets.AWS_REGION }}
          AWS_ACCOUNT_ID: ${{ secrets.AWS_ACCOUNT_ID }}
          ECR_REPOSITORY_NAME: ${{ secrets.ECR_REPOSITORY_NAME }}
          DATABASE_URL: ${{ secrets.DATABASE_URL }}
          NEXTAUTH_URL: ${{ secrets.NEXTAUTH_URL }}
          NEXTAUTH_SECRET: ${{ secrets.NEXTAUTH_SECRET }}
          ADMIN_EMAIL: ${{ secrets.ADMIN_EMAIL }}
          ADMIN_AUTH_BYPASS: ${{ secrets.ADMIN_AUTH_BYPASS }}
          EMAIL_SERVER: ${{ secrets.EMAIL_SERVER }}
          EMAIL_FROM: ${{ secrets.EMAIL_FROM }}
          S3_BUCKET_NAME: ${{ secrets.S3_BUCKET_NAME }}
          AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
          AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
          CLOUDFRONT_DOMAIN: ${{ secrets.CLOUDFRONT_DOMAIN }}
          NEXT_PUBLIC_SITE_URL: ${{ secrets.NEXT_PUBLIC_SITE_URL }}

        with:
          host: ${{ secrets.EC2_HOST_PUBLIC_ip }}
          username: ${{ secrets.EC2_USER }}
          key: ${{ secrets.EC2_SSH_KEY }}
          envs: AWS_REGION,AWS_ACCOUNT_ID,ECR_REPOSITORY_NAME,DATABASE_URL,NEXTAUTH_URL,NEXTAUTH_SECRET,ADMIN_EMAIL,ADMIN_AUTH_BYPASS,EMAIL_SERVER,EMAIL_FROM,S3_BUCKET_NAME,AWS_ACCESS_KEY_ID,AWS_SECRET_ACCESS_KEY,CLOUDFRONT_DOMAIN,NEXT_PUBLIC_SITE_URL

          script: |
            set -e
            APP_DIR="${{ secrets.EC2_PROJECT_PATH }}"
            IMAGE="$AWS_ACCOUNT_ID.dkr.ecr.$AWS_REGION.amazonaws.com/$ECR_REPOSITORY_NAME:latest"

            if ! mkdir -p "$APP_DIR" 2>/dev/null; then
              sudo mkdir -p "$APP_DIR"
              sudo chown "$USER:$USER" "$APP_DIR"
            fi

            cd "$APP_DIR"

            aws ecr get-login-password --region "$AWS_REGION" \
              | docker login --username AWS --password-stdin "$AWS_ACCOUNT_ID.dkr.ecr.$AWS_REGION.amazonaws.com"

            docker compose down || true

            cat > docker-compose.yml <<EOF
            services:
              my-app:
                image: "$IMAGE"
                container_name: jules_portfolio_app
                ports:
                  - "3000:3000"
                environment:
                  NODE_ENV: "production"
                  DATABASE_URL: "$DATABASE_URL"
                  NEXTAUTH_URL: "$NEXTAUTH_URL"
                  NEXTAUTH_SECRET: "$NEXTAUTH_SECRET"
                  ADMIN_EMAIL: "$ADMIN_EMAIL"
                  ADMIN_AUTH_BYPASS: "$ADMIN_AUTH_BYPASS"
                  EMAIL_SERVER: "$EMAIL_SERVER"
                  EMAIL_FROM: "$EMAIL_FROM"
                  AWS_REGION: "$AWS_REGION"
                  S3_BUCKET_NAME: "$S3_BUCKET_NAME"
                  AWS_ACCESS_KEY_ID: "$AWS_ACCESS_KEY_ID"
                  AWS_SECRET_ACCESS_KEY: "$AWS_SECRET_ACCESS_KEY"
                  CLOUDFRONT_DOMAIN: "$CLOUDFRONT_DOMAIN"
                  NEXT_PUBLIC_SITE_URL: "$NEXT_PUBLIC_SITE_URL"
                restart: unless-stopped
            EOF

            docker image prune -a -f || true
            docker builder prune -f || true
            docker compose pull
            docker compose up -d
            docker compose exec -T my-app npx prisma db push

13. Common Errors and Fixes

ECR authorization token
not authorized to perform: ecr:GetAuthorizationToken

Attach AmazonEC2ContainerRegistryPowerUser to the GitHub Actions IAM user.

SSH timeout
dial tcp EC2_IP:22: i/o timeout

Open inbound port 22 in the EC2 Security Group.

Permission denied creating folder
EC2_PROJECT_PATH=/home/ubuntu/portfolio-website
IMAGE variable not set

Use image: "$IMAGE" in the generated compose file, not image: ${IMAGE}.

No space left on device
docker system prune -a -f
docker volume prune -f
df -h

Better long-term fix: use a 30 GB EC2 disk.

MongoDB URL missing database name

Correct URL:

mongodb+srv://USER:PASSWORD@CLUSTER.mongodb.net/jules_portfolio_cms?retryWrites=true&w=majority
